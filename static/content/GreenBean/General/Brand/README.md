# Isotipos de GreenBean

Archivos originales entregados por el propietario, conservados sin modificar.

| Archivo | Uso |
| --- | --- |
| `greenbean-8EB69B.png` | Isotipo verde claro para Dark Mode. |
| `greenbean-235347.png` | Isotipo verde oscuro para Light Mode. |

Ambos PNG tienen transparencia y dimensiones de 1254 × 1254 px. La cabecera puede encuadrar el área visible sin alterar los archivos originales.

El backend publica sus URLs en `GET /api/resources/general/getStaticIcons`, dentro de `staticcontent`: ID 2 para Dark Mode e ID 3 para Light Mode. Las URLs del contrato fijan el commit de los recursos.
