# CV públicos del fundador

Copias PDF autorizadas por Marco para descargar desde el portafolio.
ES: 2 páginas. EN: 3 páginas. Archivos originales, sin reexportar.

Revisión estructural (pypdf, 20-09-2026): PDF 1.5 válidos, sin cifrado,
sin JavaScript, adjuntos, formularios XFA ni acciones Launch/SubmitForm/ImportData.
OpenAction solo navega a una página interna con GoTo/Fit.
Enlaces internos del PDF: teléfono, correo y perfil de LinkedIn del fundador.
Esto no equivale a un análisis antivirus ni garantiza ausencia de vulnerabilidades.

rama mutable. Para actualizar un CV se debe revisar el PDF y actualizar el SHA.

los originales en Drive son independientes y no se modifican al subir estas copias.
